> แนวโน้มการย้ายการประมวลผลจาก "ศูนย์กลาง (cloud)" ไปสู่ "ขอบเครือข่าย (edge)" ที่ใกล้ผู้ใช้/ข้อมูล

## เส้นเรื่อง
[Edge Computing](/concept/edge-computing) ลดความหน่วง ประหยัดแบนด์วิดท์ และเพิ่มความเป็นส่วนตัว ปรากฏซ้ำหลายหัวข้อ:
- ระดับฮาร์ดแวร์/ซอฟต์แวร์ → [สัปดาห์ที่ 2: Hardware & Software Ecosystems](/module/02)
- ระดับเครือข่าย (Edge networks, 5G/6G) → [สัปดาห์ที่ 6: Computer Networks & Internet](/module/06)
- ระดับอุปกรณ์ ([TinyML และ Edge AI](/concept/tinyml-edge-ai) บนไมโครคอนโทรลเลอร์) → [สัปดาห์ที่ 11: Embedded Systems & IoT](/module/11)

## บทเรียนสำคัญ
สถาปัตยกรรมสมัยใหม่เป็น "สเปกตรัม" ระหว่าง cloud ↔ edge ไม่ใช่ทางเลือกขั้วเดียว — การออกแบบต้องสมดุลระหว่างพลังประมวลผล พลังงาน ความหน่วง และความเป็นส่วนตัว
