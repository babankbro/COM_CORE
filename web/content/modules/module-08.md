## คำถามนำ
เราจะเชื่อมความรู้สัปดาห์ 1-7 เป็นภาพระบบเดียวได้อย่างไร?

## ผลลัพธ์การเรียนรู้ย่อย
1. ทบทวน CE ecosystem ตั้งแต่ hardware ถึง cloud
2. ฝึกแก้โจทย์วิเคราะห์ ไม่ใช่จำคำศัพท์
3. เตรียมสอบกลางภาคตาม CLO1-CLO3

## แก่นความรู้ที่ต้องเข้าใจ
- หัวข้อก่อนกลางภาคเรียงจากภาพรวมสาขา → hardware/software → logic/processor → programming → database → network → cloud
- โจทย์ที่ดีมักให้สถานการณ์ระบบหนึ่ง แล้วถามให้แยกองค์ประกอบ ออกแบบข้อมูล หรืออธิบาย trade-off
- การทบทวนควรทำเป็น concept map และ practice problems มากกว่าการอ่านซ้ำอย่างเดียว

## เนื้อหาเรียนรู้
- ให้ผู้เรียนเลือกโครงงานเกม/web app ที่ทำมา แล้ว map ว่าใช้ความรู้จากสัปดาห์ใดบ้าง เช่น logic อยู่ใน game rule, database อยู่ใน save/load, network อยู่ใน API
- ทบทวนด้วยโจทย์ผสม: ออกแบบ ER diagram, เขียน pseudocode, คำนวณเลขฐาน, อธิบาย TCP/UDP และคำนวณ PUE
- ให้ผู้เรียนทำ one-page cheat sheet เชิงแนวคิด แม้ใช้ไม่ได้ในสอบ แต่กระบวนการสรุปจะเผยช่องว่างความเข้าใจ

### W1 ภาพรวมวิศวกรรมคอมพิวเตอร์ (CLO1)
- **ต้องรู้:** CE เน้นจุดที่ hardware พบ software ต่างจาก CS (ทฤษฎี/อัลกอริทึม), SE (กระบวนการพัฒนาซอฟต์แวร์), IT (ดูแลระบบให้ผู้ใช้) และ IS (ข้อมูลเพื่อองค์กร); กรอบหลักสูตร ACM/IEEE; บทบาท AI และ Agentic AI ในงานวิศวกรรม
- **ฝึก:** งาน "ออกแบบ firmware และวงจรควบคุมมอเตอร์ของหุ่นยนต์" ตรงกับสาขาใดที่สุด เพราะอะไร — *เฉลย: CE เพราะต้องออกแบบทั้งวงจรและซอฟต์แวร์ระดับล่างร่วมกัน*
- **อ่านทบทวน:** [สัปดาห์ที่ 1](/module/01) · [ทบทวนหัวข้อ 1](/module/08/01) · [Lab 01](/lab/01)

### W2 ฮาร์ดแวร์ ซอฟต์แวร์ และระบบนิเวศ (CLO1)
- **ต้องรู้:** CPU (งานทั่วไป ตามลำดับ) / GPU (ขนาน จำนวนมาก) / NPU (อนุมาน AI ประหยัดไฟ); memory hierarchy ยิ่งใกล้ CPU ยิ่งเร็ว เล็ก และแพง; OS จัดการ process, memory, file, I/O; edge vs cloud; green และ heterogeneous computing
- **ฝึก:** เรียงจากเร็วที่สุด: RAM, SSD, register, L1 cache — *เฉลย: register → L1 cache → RAM → SSD*
- **อ่านทบทวน:** [สัปดาห์ที่ 2](/module/02) · [ทบทวนหัวข้อ 1](/module/08/01) · [Lab 02](/lab/02)

### W3 วงจรตรรกะและหน่วยประมวลผล (CLO2)
- **ต้องรู้:** แปลงเลขฐาน 2/10/16; two's complement; AND/OR/NOT/XOR/NAND และตารางความจริง; half adder (Sum = A XOR B, Carry = A AND B); von Neumann vs Harvard; RISC vs CISC และ RISC-V; chiplet
- **ฝึก:** แปลง 45₁₀ เป็นฐานสองและฐานสิบหก — *เฉลย: 45 = 32 + 8 + 4 + 1 = 101101₂ = 2D₁₆*
- **อ่านทบทวน:** [สัปดาห์ที่ 3](/module/03) · [ทบทวนหัวข้อ 2](/module/08/02) · [Lab 03](/lab/03)

### W4 อัลกอริทึมและการเขียนโปรแกรม (CLO3)
- **ต้องรู้:** computational thinking 4 ขั้น (decomposition, pattern, abstraction, algorithm); เขียน pseudocode/flowchart; อ่าน Big-O จากจำนวนชั้นของ loop; linear O(n) vs binary O(log n) (ต้องเรียงข้อมูลก่อน); OOP vs functional; Git
- **ฝึก:** ข้อมูลเรียงแล้ว 1,000 ตัว binary search เปรียบเทียบอย่างมากกี่ครั้ง — *เฉลย: ⌊log₂1000⌋ + 1 = 9 + 1 = 10 ครั้ง (linear อาจถึง 1,000 ครั้ง)*
- **อ่านทบทวน:** [สัปดาห์ที่ 4](/module/04) · [ทบทวนหัวข้อ 3](/module/08/03) · [Lab 04](/lab/04)

![กราฟแท่งสเกล log เทียบจำนวนครั้งเปรียบเทียบกรณีแย่สุดของ linear search ซึ่งเท่ากับ n กับ binary search ซึ่งเพิ่มจาก 4 ครั้งที่ n เท่ากับ 10 เป็นเพียง 20 ครั้งที่ n เท่ากับหนึ่งล้าน](/images/weeks/w08-search-steps.svg)

### W5 ฐานข้อมูลและการจัดการข้อมูล (CLO3)
- **ต้องรู้:** ER diagram และ cardinality (1:1, 1:N, M:N ต้องมีตารางกลาง); primary key / foreign key; 1NF–3NF; SQL SELECT–WHERE–JOIN–GROUP BY; ACID; SQL vs NoSQL; vector database กับ embedding
- **ฝึก:** เขียน SQL แสดงชื่อและ GPA ของนักศึกษาที่ GPA มากกว่า 3.00 เรียงจากมากไปน้อย — *เฉลย:* `SELECT name, gpa FROM students WHERE gpa > 3.00 ORDER BY gpa DESC;`
- **อ่านทบทวน:** [สัปดาห์ที่ 5](/module/05) · [ทบทวนหัวข้อ 4](/module/08/04) · [Lab 05](/lab/05)

### W6 เครือข่ายคอมพิวเตอร์และอินเทอร์เน็ต (CLO1)
- **ต้องรู้:** OSI 7 ชั้น vs TCP/IP 4 ชั้น; TCP (ครบ เรียง) vs UDP (เร็ว เบา); DNS, DHCP, HTTP/HTTPS และพอร์ตหลัก (53, 80, 443); IPv4 32 บิต vs IPv6 128 บิต; private IP กับ NAT; คำนวณ subnet
- **ฝึก:** `192.168.5.0/27` มี mask อะไรและมี host ใช้งานได้กี่เครื่อง — *เฉลย: host bits = 32 − 27 = 5 → 2⁵ = 32 ที่อยู่ → ใช้ได้ 30 เครื่อง, mask = 255.255.255.224*
- **อ่านทบทวน:** [สัปดาห์ที่ 6](/module/06) · [ทบทวนหัวข้อ 5](/module/08/05) · [Lab 06](/lab/06)

![ภาพแยก 32 บิตของ prefix /26 เป็นบิต network 26 บิตและบิต host 6 บิต ได้ mask 255.255.255.192 และแบ่ง 192.168.10.0/24 เป็นสี่ subnet ขนาด 64 ที่อยู่ พร้อม network address broadcast address และช่วง host ของแต่ละ subnet](/images/weeks/w08-subnet.svg)

### W7 ศูนย์ข้อมูลและโครงสร้างพื้นฐานคลาวด์ (CLO2, CLO4)
- **ต้องรู้:** องค์ประกอบ data center; VM (มี Guest OS) vs container (แชร์ kernel); Docker image vs container; Kubernetes; IaaS/PaaS/SaaS และ public/private/sovereign; PUE และ DCiE; liquid cooling
- **ฝึก:** IT ใช้ 800 kW และ PUE = 1.25 ไฟรวม, Non-IT และ DCiE เท่าไร — *เฉลย: Total = 1.25 × 800 = 1,000 kW, Non-IT = 200 kW, DCiE = 800/1,000 = 80%*
- **อ่านทบทวน:** [สัปดาห์ที่ 7](/module/07) · [ทบทวนหัวข้อ 5](/module/08/05) · [Lab 07](/lab/07)

### คู่แนวคิดที่ข้อสอบชอบให้เปรียบเทียบ
| คู่แนวคิด | ตัวแรก | ตัวหลัง | คำถามที่ใช้ตัดสินใจ |
| :--- | :--- | :--- | :--- |
| Combinational vs Sequential (W3) | output ขึ้นกับ input ปัจจุบัน | มีหน่วยความจำ (flip-flop) | ต้องจำสถานะก่อนหน้าไหม |
| Linear vs Binary search (W4) | O(n) ไม่ต้องเรียง | O(log n) ต้องเรียงก่อน | ข้อมูลเรียงแล้วหรือค้นบ่อยไหม |
| SQL vs NoSQL (W5) | schema ชัด, JOIN, ACID | schema ยืดหยุ่น, scale แนวนอน | ข้อมูลมีโครงสร้างตายตัวและต้องถูกต้องสูงไหม |
| TCP vs UDP (W6) | ครบถ้วน เรียงลำดับ | หน่วงต่ำ overhead ต่ำ | ข้อมูลหายได้บ้างไหม |
| VM vs Container (W2, W7) | แยกขาด มี Guest OS | เบา แชร์ kernel | ต้องรัน OS ต่างชนิดหรือแยกขาดไหม |
| Edge vs Cloud (W2, W6) | ใกล้ผู้ใช้ หน่วงต่ำ | ทรัพยากรมาก รวมศูนย์ | ต้องตอบภายในกี่มิลลิวินาที |

### กลยุทธ์ตอบข้อสอบแบบกรณีศึกษา (ตัวอย่างทำทีละขั้น)
โจทย์ตัวอย่าง: *"ร้านกาแฟต้องการระบบสะสมแต้มผ่านเว็บ รองรับลูกค้า 5,000 คน"*
1. **จับความต้องการและข้อจำกัด:** ต้องเก็บแต้มถูกต้อง (ห้ามหาย), ผู้ใช้ไม่มาก, งบน้อย
2. **map ลงชั้นของระบบ:** ข้อมูล (W5) → ตาราง `customers` กับ `transactions` แบบ 1:N; อัลกอริทึม (W4) → ค้นลูกค้าด้วยเบอร์โทรผ่าน index; เครือข่าย (W6) → HTTPS บน TCP; คลาวด์ (W7) → PaaS
3. **เลือกพร้อม trade-off:** ใช้ SQL เพราะต้องการ ACID แม้ scale แนวนอนยากกว่า; ใช้ PaaS เพราะทีมเล็กไม่ต้องดูแล OS แต่ควบคุมได้น้อยกว่า IaaS
4. **ยืนยันด้วยตัวเลขหรือเหตุผลที่ตรวจได้:** เช่น ค้นด้วย index ระดับ O(log n) แทนการไล่ทั้งตาราง O(n)

### สรุปสั้น
- ทบทวนเป็นภาพระบบเดียว: logic → hardware → algorithm → database → network → cloud
- โจทย์คำนวณที่ต้องทำได้คล่อง: เลขฐาน/two's complement, Big-O และ log₂n, subnet, PUE/DCiE
- ทุกคำตอบเชิงออกแบบต้องมี "เลือกอะไร + เพราะอะไร + แลกกับอะไร"
- ทำโจทย์ฝึกทั้ง 7 ข้อด้านบนโดยไม่เปิดเฉลย ข้อที่พลาดคือสัปดาห์ที่ต้องกลับไปอ่านก่อน
