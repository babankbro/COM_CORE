## Definition
ฐานข้อมูลที่ออกแบบมาเก็บและค้นหา **เวกเตอร์ฝังตัว (embeddings)** มิติสูง ด้วยการค้นความคล้าย (similarity search) รองรับงาน AI เช่น semantic search, ระบบแนะนำ และ [RAG](/concept/rag-llm)

## Course Context
หมวด NoSQL ใหม่ที่สำคัญในหัวข้อฐานข้อมูล ([สัปดาห์ที่ 5: Database & Data Management](/module/05)) และเชื่อมกับ AI ([สัปดาห์ที่ 10: Generative AI & Modern Robotics](/module/10)); ปี 2025 ตลาดแตะ ~3.2 พันล้านดอลลาร์ โต ~24%/ปี และฐานข้อมูลหลัก (เช่น SQL Server 2025) เริ่มผนวกชนิด `VECTOR` เข้าไป
