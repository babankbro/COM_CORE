✨ 1. Generative AI และ LLM

Discriminative = "กรรมการ" แยก/จำแนก (สแปมไหม?) · Generative = "จิตรกร" สร้างข้อมูลใหม่ (ข้อความ ภาพ โค้ด เสียง)

Tokenหน่วยย่อยที่โมเดลเห็น (คำ/ส่วนของคำ/ตัวอักษร) · คิดค่าบริการและจำกัดความยาวเป็น token
Embeddingเวกเตอร์ "พิกัดความหมาย" คำที่ความหมายใกล้กันอยู่ใกล้กัน
Transformerสถาปัตยกรรมหลักของ LLM ใช้ self-attention ให้แต่ละ token มอง token อื่นในบริบท
Promptข้อความนำเข้า (system + user + context) ที่กำหนดงานและรูปแบบคำตอบ
Context windowจำนวน token สูงสุดที่โมเดลรับได้ต่อครั้ง ("ความจำระยะสั้น")

สร้าง LLM: pre-training (ทำนาย token ถัดไปจากข้อความมหาศาล) → fine-tuning / RLHF (ให้ทำตามคำสั่งและปลอดภัยขึ้น) · ภาพใช้ diffusion model

📚 3. RAG: Retrieval-Augmented Generation

Indexing: เอกสาร → แบ่ง chunk → embedding → vector DB (เช่น pgvector) · Query: embed คำถาม → ค้น top-k → ประกอบ prompt (คำสั่ง + context + คำถาม) → LLM ตอบพร้อมอ้างอิง

cos θ = (A · B) / (‖A‖ × ‖B‖)  ·  1 = ทิศเดียวกัน, 0 = ไม่เกี่ยวกัน

ตัวอย่าง q = [0.9, 0.1, 0.2], A = [0.8, 0.2, 0.1] → q·A = 0.76, ‖q‖ = 0.927, ‖A‖ = 0.831 → cos = 0.987 (top-1)

🛠️ 4. Agentic AI

Chatbot ตอบ · Agent ลงมือทำหลายขั้นเอง: เป้าหมาย → คิด/วางแผน (LLM) → เรียก tool → สังเกตผล → วนซ้ำ (ReAct = Reason + Act)

Tool useLLM ส่งคำขอเรียกฟังก์ชัน (ชื่อ + อาร์กิวเมนต์ JSON) โปรแกรมของเราเป็นผู้รันจริง
MCPModel Context Protocol มาตรฐานเชื่อมแอป AI กับเครื่องมือ/ข้อมูล ("USB-C ของ AI")
Guardrailsleast privilege · จำกัดจำนวนรอบ · audit log · sandbox · human approval ก่อนงานเสี่ยง
🦾 5. Physical AI และหุ่นยนต์
Sense (กล้อง LiDAR IMU) → Perceive → Plan → Act (มอเตอร์ แขนกล) → วนซ้ำ
  • ROS 2 = middleware สื่อสารระหว่าง node ของหุ่นยนต์ (topic publish/subscribe)
  • Sim-to-Real: ฝึก/ทดสอบใน simulation ก่อน แล้วย้ายสู่หุ่นจริง (ระวัง reality gap)
  • VLA (Vision-Language-Action): โมเดลรับภาพ + คำสั่งภาษา → ส่งคำสั่งการเคลื่อนไหว
  • Humanoid: ใช้ได้กับสภาพแวดล้อมที่ออกแบบมาสำหรับคน (บันได ประตู เครื่องมือ)

ผิดพลาดในแชต = ข้อความผิด · ผิดพลาดในหุ่นยนต์ = แรง/การชนจริง → ต้องมี e-stop, จำกัดความเร็ว/แรง, safety zone

⚠️ ข้อผิดพลาดที่พบบ่อย
  • เชื่อคำตอบ LLM ทันทีเพราะภาษาลื่นไหล → hallucination ต้องตรวจกับแหล่งจริง
  • คิดว่า RAG = ฝึกโมเดลใหม่ (จริง ๆ แค่แนบเอกสารเข้า prompt)
  • ใส่ข้อมูลส่วนตัว/ความลับลง prompt หรือ push API key ขึ้น GitHub
  • ปล่อยให้ agent มีสิทธิ์เกินจำเป็น (ลบไฟล์/ส่งอีเมล) โดยไม่มีคนอนุมัติ
  • ลืมว่าเอกสารที่ค้นมาอาจมี prompt injection แฝงคำสั่ง
✅ เช็กความเข้าใจ
  • อธิบาย token, embedding, prompt, context window ได้
  • บอกผลของ temperature ต่อความน่าจะเป็นของ token ได้
  • คำนวณ cosine similarity และเรียงขั้นตอน RAG ได้
  • แยก chatbot กับ agent และระบุ guardrails ≥ 3 ข้อ
  • อธิบาย sense-plan-act และความเสี่ยงทางกายภาพของหุ่นยนต์
