🐳 3. Docker · Kubernetes

Dockerfile (สูตร) → build → image (อ่านอย่างเดียว, เป็นชั้น layer) → run → container (กำลังทำงาน)

FROM python:3.12-slim WORKDIR /app COPY requirements.txt . RUN pip install -r requirements.txt # แยกชั้น → ใช้ cache COPY . . EXPOSE 5000 # เอกสาร ไม่ได้เปิดพอร์ตเอง CMD ["python", "app.py"]
docker build -t asset-app . docker run -d -p 8080:5000 asset-app # host:container docker ps · docker logs <id> · docker stop <id> docker compose up -d # หลายบริการพร้อมกัน

Kubernetes = orchestration: Pod (หน่วยเล็กสุด) · Deployment (replicas: 3) · Service · self-healing, auto-scaling, rolling update แบบ declarative (YAML)

📄 Kubernetes Deployment (YAML ย่อ)
apiVersion: apps/v1 kind: Deployment metadata: { name: asset-app } spec: replicas: 3 # ต้องมี 3 pod เสมอ ล่มแล้วสร้างใหม่ selector: { matchLabels: { app: asset } } template: metadata: { labels: { app: asset } } spec: containers: - name: web image: asset-app:1.0 ports: [{ containerPort: 5000 }]

declarative = บอก "สภาพที่ต้องการ" แล้ว K8s คอยปรับของจริงให้ตรงเอง (kubectl apply -f app.yaml)

⚡ 6. PUE · DCiE (The Green Grid)
PUE = พลังงานรวมของ data center ÷ พลังงาน IT  (≥ 1, ยิ่งต่ำยิ่งดี)
Non-IT = (PUE − 1) × IT
DCiE = IT ÷ Total × 100%

ตัวอย่าง IT 400 kW, รวม 560 kW → PUE 1.4 · DCiE ≈ 71.4% · Non-IT 160 kW → 160 × 8,760 × 4 บาท = 5,606,400 บาท/ปี

ลดเป็น PUE 1.1 → Total 440 kW · ประหยัด 120 kW × 8,760 × 4 = 4,204,800 บาท/ปี

kW = กำลัง (อัตรา) · kWh = พลังงาน (kW × ชั่วโมง) → ค่าไฟคิดจาก kWh

⚠️ ข้อผิดพลาดที่พบบ่อย
  • คิดว่า container มี OS เต็มชุดเหมือน VM (จริง ๆ แชร์ kernel)
  • สับสน image (แม่แบบ) กับ container (ตัวที่กำลังรัน)
  • สลับ -p 8080:5000 — ตัวหน้าคือพอร์ตของ host
  • คิดว่าใช้ SaaS แล้วไม่ต้องดูแลข้อมูล/สิทธิ์ผู้ใช้
  • หาร PUE กลับด้าน (IT ÷ Total คือ DCiE) หรือได้ PUE < 1
  • คูณค่าไฟด้วย kW โดยไม่คูณจำนวนชั่วโมง
✅ เช็กความเข้าใจ
  • บอกองค์ประกอบ 6 ส่วนของ data center และเหตุผลของ redundancy ได้
  • วาดชั้น VM vs container และเลือกใช้ได้ตามสถานการณ์
  • เขียน Dockerfile, build, run และอธิบาย port mapping ได้
  • บอกหน้าที่ Kubernetes (replica, self-healing, scaling) ได้
  • จำแนกบริการเป็น IaaS/PaaS/SaaS และ public/private/sovereign ได้
  • คำนวณ PUE, DCiE, Non-IT และค่าไฟต่อปีได้
