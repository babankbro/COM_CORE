🏷️ 2. Feature · Label · Model · Training vs Inference
Feature (X)ข้อมูลขาเข้า เช่น น้ำหนัก สีผลไม้ อุณหภูมิ ความชื้น
Label (y)คำตอบที่ถูก (มีเฉพาะ supervised)
Trainingปรับ parameter (w, b) จาก train set ให้ loss ต่ำ
Inferenceใช้โมเดลที่ฝึกแล้วทำนายข้อมูลใหม่ (prediction)

แบ่ง train/test (เช่น 80/20) วัดผลบนข้อมูลที่โมเดลไม่เคยเห็น · train ดีมาก test แย่ = overfitting · แย่ทั้งคู่ = underfitting

🔀 3. สามรูปแบบการเรียนรู้
แบบข้อมูลตัวอย่างงาน / อัลกอริทึม
SupervisedX + labelClassification (สแปม/ไม่สแปม), Regression (ทำนายอุณหภูมิ) · Logistic/Linear Regression, Tree
UnsupervisedX อย่างเดียวClustering ลูกค้า, หา anomaly เซนเซอร์ · k-means, PCA, Isolation Forest
Reinforcementstate, action, rewardเกม, หุ่นยนต์เดิน, ควบคุมแอร์ · ลองผิดลองถูกให้ reward สะสมสูงสุด

Classification ตอบ "แบบไหน?" (หมวดหมู่) · Regression ตอบ "เท่าไร?" (ค่าต่อเนื่อง)

🧮 4. นิวรอนเทียม: Weighted Sum + Activation
z = Σ wᵢxᵢ + b   →   ŷ = σ(z) = 1 / (1 + e−z)
Step: z ≥ 0 → 1
ReLU = max(0, z)
σ(0) = 0.5

ตัวอย่าง x = [0.8, 0.6], w = [1.5, 0.5], b = −1.0 → z = 1.2 + 0.3 − 1.0 = 0.5 → σ(0.5) = 0.622 · y = 1 → loss (y − ŷ)² = 0.143

gradient descent 1 รอบ (lr = 1): w → [1.642, 0.606], b → −0.823 → ŷ = 0.702, loss = 0.089 (ลดลง)

MLP = หลายนิวรอนหลายชั้น · ฝึกด้วย loss → gradient → backpropagation (chain rule) → ปรับ w

🧱 5. Deep Learning และคุณภาพข้อมูล
ML ดั้งเดิมDeep Learning
Featureคนออกแบบเอง (feature engineering)โมเดลเรียนเองจากข้อมูลดิบ
ข้อมูล / ฮาร์ดแวร์น้อย–ปานกลาง · CPU พอมาก · GPU/NPU (คูณเมทริกซ์ขนาน)
เหมาะกับข้อมูลตาราง อธิบายได้ง่ายภาพ เสียง ข้อความ (CNN, RNN, Transformer)

Garbage in, garbage out: คุณภาพข้อมูล = ความถูกต้อง · ครบถ้วน · สม่ำเสมอ · ทันสมัย · เป็นตัวแทนประชากร

Bias เกิดได้ทุกขั้น: เก็บข้อมูล (sampling bias) · ติด label · เลือก feature · ใช้งานผิดบริบท · แก้ด้วย datasheet และตรวจผลแยกกลุ่ม

📏 6. วัดผล Regression: MAE · MSE · RMSE (Lab 09)
ŷ = mx + c
e = y − ŷ
MAE = (1/N)Σ|eᵢ|
MSE = (1/N)Σeᵢ²
RMSE = √MSE

ตัวอย่าง y = [30, 32, 31, 35], ŷ = [31, 31, 33, 34] → e = [−1, 1, −2, 1] → MAE = 1.25 · MSE = 7/4 = 1.75 · RMSE = 1.32 °C

ห้ามบวก error ตรง ๆ (บวก/ลบหักล้างกัน) · MSE ลงโทษ error ใหญ่หนัก หน่วยเป็นกำลังสอง · RMSE/MAE หน่วยเดียวกับ y

💻 Gradient Descent 1 รอบ (จาก Lab 09)
∂L/∂m = (2/N)Σ eᵢxᵢ  ·  ∂L/∂c = (2/N)Σ eᵢ  (e = ŷ − y)  ·  m ← m − lr·∂L/∂m
xs = [0, 1, 2, 3] ys = [1, 3, 4, 8] m, c, lr = 2, 1, 0.05 N = len(xs) e = [(m * x + c) - y for x, y in zip(xs, ys)] # e = y_hat - y grad_m = (2 / N) * sum(ei * xi for ei, xi in zip(e, xs)) grad_c = (2 / N) * sum(e) m = m - lr * grad_m # เดินลงเขา: ลบ gradient c = c - lr * grad_c print(e, grad_m, grad_c, round(m, 4), c) # [0, 0, 1, -1] -0.5 0.0 2.025 1.0

gradient เป็นลบ → m เพิ่มขึ้น · lr ใหญ่เกิน loss แกว่ง/ระเบิด · lr เล็กเกิน เรียนช้า · ฝึก 1,000 epoch ได้ m = 2.2, c = 0.7

🔁 7. ML Lifecycle · MLOps · NIST AI RMF

ข้อมูล → เตรียม/ทำความสะอาด → ฝึก → ประเมิน → deploy → monitor → retrain (วนซ้ำ)

แนวคิดความหมาย
Versioning / Registryเก็บเวอร์ชันข้อมูล + โมเดล ย้อนกลับ (rollback) ได้
CI / CD / CTทดสอบ · deploy · ฝึกใหม่อัตโนมัติ (continuous training)
Data driftข้อมูลจริงเปลี่ยนไปจากตอนฝึก → ความแม่นยำลดเงียบ ๆ
Data leakageข้อมูล test/อนาคตรั่วเข้าการฝึก → ผลดีเกินจริง

NIST AI RMF: Govern · Map · Measure · Manage — ดูมากกว่า accuracy: validity, safety, security, fairness, accountability

⚠️ ข้อผิดพลาดที่พบบ่อย
  • คิดว่า AI = ML = DL เป็นคำเดียวกัน (จริง ๆ ซ้อนกันเป็นชั้น)
  • วัดผลบน train set แล้วสรุปว่าโมเดลดี → ต้องใช้ test set ที่แยกไว้
  • สับสน training (ปรับ w) กับ inference (ใช้ w ที่ได้ทำนาย)
  • ผสม sign convention e = y − ŷ กับ e = ŷ − y ในโค้ดเดียวกัน
  • ตั้งชื่อตัวแปร mse แต่คำนวณ |e| (นั่นคือ MAE)
  • deploy แล้วไม่ monitor → ไม่รู้ว่าเกิด data drift / bias
✅ เช็กความเข้าใจ
  • แยก AI / ML / DL / GenAI พร้อมตัวอย่างได้
  • บอกได้ว่าโจทย์เป็น supervised / unsupervised / reinforcement
  • คำนวณ z และ σ(z) ของนิวรอนด้วยมือได้ (เช่น z = 0 → 0.5)
  • คำนวณ MAE, MSE, RMSE และอธิบายความต่างได้
  • อธิบายว่าทำไมต้อง monitor โมเดลหลัง deploy และ bias เกิดได้ที่ขั้นใด
  1. w = [2, −1], x = [1, 1], b = 1 → z = ? σ(z) = ?
  2. y = [10, 12, 14], ŷ = [11, 12, 12] → MAE, MSE, RMSE = ?
  3. ข้อมูลลูกค้าไม่มี label ต้องการแบ่งกลุ่ม ควรใช้การเรียนรู้แบบใด

เฉลย: (1) z = 2, σ(2) ≈ 0.881 · (2) e = [−1, 0, 2] → MAE = 1.0, MSE = 5/3 ≈ 1.67, RMSE ≈ 1.29 · (3) unsupervised (เช่น k-means)
