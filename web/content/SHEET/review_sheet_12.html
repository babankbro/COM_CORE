🔐 2. Cryptography
ชนิดกุญแจตัวอย่างใช้ทำอะไร
Symmetricดอกเดียวกัน ล็อก+เปิดAES (DES เลิกใช้)เข้ารหัสข้อมูลปริมาณมาก เร็ว
Asymmetricpublic ล็อก · private เปิดRSA, ECCแลกกุญแจ, ลายเซ็นดิจิทัล, certificate
Hashไม่มีกุญแจ ทางเดียวSHA-256, SHA-3 (MD5 ไม่ปลอดภัย)ตรวจ integrity, เก็บรหัสผ่าน (แบบ slow+salt)

Digital signature: sign ด้วย private → ใครก็ verify ด้วย public → ยืนยันผู้ส่ง + integrity

TLS/HTTPS = hybrid: asymmetric ยืนยัน certificate และตกลง session key → AES เข้ารหัสข้อมูลจริง

📡 4. Security สำหรับ IoT (เชื่อม W11)
  • เปลี่ยน default password และใช้ credential/certificate แยกรายอุปกรณ์
  • MQTT over TLS (พอร์ต 8883) + authentication + ACL ราย topic
  • secure boot และ OTA update ที่ตรวจลายเซ็นเฟิร์มแวร์ก่อนติดตั้ง
  • แยกเครือข่าย IoT (VLAN/segment) ออกจากเครื่องผู้ใช้ · ตรวจช่วงค่าที่สมเหตุสมผลก่อนสั่ง actuator

⚠️ ข้อผิดพลาดที่พบบ่อย
  • สับสน hash กับ encryption: hash ย้อนกลับไม่ได้ ไม่มีกุญแจ
  • "เข้ารหัส" รหัสผ่านด้วย AES หรือเก็บเป็น MD5/SHA-256 ไม่มี salt
  • คิดว่าเข้ารหัสแล้วครบ CIA (encryption ช่วย C แต่ไม่ช่วย A)
  • แก้ SQL injection ด้วยการลบเครื่องหมาย ' เองแทน parameterized query
  • มองว่า Zero Trust คือผลิตภัณฑ์ที่ซื้อได้ ทั้งที่เป็นสถาปัตยกรรม/แนวคิด
  • ใช้ username/password เดียวกันทั้ง dashboard และ MQTT broker
✅ เช็กความเข้าใจ
  • วิเคราะห์ incident ว่า C, I หรือ A เสีย และเสนอ control ให้ตรงด้านได้
  • อธิบายว่าทำไม TLS ใช้ทั้ง asymmetric และ symmetric
  • เขียน parameterized query และเก็บรหัสผ่านด้วย bcrypt/Argon2id ได้
  • เปรียบเทียบ perimeter กับ Zero Trust และบอกบทบาท PDP/PEP ได้
  • ทำ threat model ของ IoT dashboard พร้อม control อย่างน้อย 5 รายการ
