SELECT c.name, COUNT(*) AS n FROM enrollments e JOIN courses c ON e.course_id = c.id GROUP BY c.name HAVING COUNT(*) > 30 -- ฟังก์ชันรวมกรองด้วย HAVING ORDER BY n DESC;

⚖️ คู่แนวคิดที่ข้อสอบชอบให้เปรียบเทียบ
คู่ถามตัวเองว่า…
Combinational vs Sequential (W3)ต้องจำสถานะก่อนหน้า (flip-flop) ไหม
von Neumann vs Harvard (W3)คำสั่งกับข้อมูลใช้หน่วยความจำ/บัสร่วมกันไหม
Linear vs Binary (W4)ข้อมูลเรียงแล้วหรือยัง ค้นบ่อยไหม
SQL vs NoSQL (W5)โครงสร้างตายตัว + ต้องการ ACID ไหม
TCP vs UDP (W6)ข้อมูลหายได้บ้างไหม ต้องหน่วงต่ำแค่ไหน
VM vs Container (W2, W7)ต้องรัน OS ต่างชนิด / แยกขาดไหม
