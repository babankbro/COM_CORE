# 🧪 กิจกรรมปฏิบัติการ (Labs) และโครงงาน (Mini-Projects)

> เพื่อตอบสนองเวลาเรียนที่จำกัด (Lab 2 ชม./สัปดาห์) และความต้องการให้นักศึกษาได้พัฒนาทักษะเชิงลึก กิจกรรมปฏิบัติการจะถูกจัดรูปแบบเป็น **4 โมดูล Mini-Project (โมดูลละ 4 สัปดาห์)** โดยใน 1 คาบ (2 ชม.) จะแบ่งเป็น:
> - **ชั่วโมงที่ 1:** ปฏิบัติการ/ทดลองพื้นฐานที่สอดคล้องกับเนื้อหาทฤษฎีในสัปดาห์นั้น
> - **ชั่วโมงที่ 2:** การทำงานกลุ่มสำหรับ Mini Project (บวกเวลาศึกษาด้วยตนเองนอกคาบเพื่อเสริมให้ครบ 8 ชม./โปรเจกต์)

## 📦 โครงสร้าง 4 โมดูล (4 Mini-Projects)

### 🟩 Module 1: The Foundation & Programming (สัปดาห์ 1 - 4)
**Mini Project 1: "Simple Text/2D Game"** (ทักษะเขียนโปรแกรมเกมเบื้องต้น)
- **W1:** Lab 1 ชม. (ตั้งค่า IDE, Git) + Project 1 ชม. (ออกแบบโครงสร้างและกติกาเกมด้วย Python)
- **W2:** Lab 1 ชม. (ตรวจสอบสเปกฮาร์ดแวร์) + Project 1 ชม. (ทำระบบ Save/Load และเขียนโค้ดอ่านเขียนไฟล์)
- **W3:** Lab 1 ชม. (จำลองวงจร Logisim) + Project 1 ชม. (เขียนเงื่อนไข/ตรรกะ (Game Logic) ของตัวเกม)
- **W4:** Lab 1 ชม. (วิเคราะห์ Big-O/Flowchart) + Project 1 ชม. (สรุป นำเสนอ และสาธิตการเล่นเกม)

### 🟦 Module 2: Web Development & Infrastructure (สัปดาห์ 5 - 8)
**Mini Project 2: "Asset Management Web App"** (ทักษะสร้างเว็บและฐานข้อมูล)
- **W5:** Lab 1 ชม. (ออกแบบ ER และ SQL) + Project 1 ชม. (ต่อฐานข้อมูล SQLite กับ Python/Node.js)
- **W6:** Lab 1 ชม. (Network simulation/Ping) + Project 1 ชม. (สร้าง API และ Web Router)
- **W7:** Lab 1 ชม. (ทดลองใช้ Cloud/Docker เบื้องต้น) + Project 1 ชม. (Deploy เว็บแอปพลิเคชันขึ้นเซิร์ฟเวอร์)
- **W8 (Midterm):** สอบกลางภาค (ครอบคลุมทฤษฎีและเนื้อหา Module 1-2)

### 🟧 Module 3: IoT & Smart Systems (สัปดาห์ 9 - 12)
**Mini Project 3: "Smart Environment Monitor"** (ทักษะสร้างระบบ IoT)
- **W9:** Lab 1 ชม. (ทดลองรัน ML Model ง่ายๆ) + Project 1 ชม. (วางแผนสถาปัตยกรรม IoT)
- **W10:** Lab 1 ชม. (เรียกใช้งาน GenAI API) + Project 1 ชม. (ต่อวงจรบอร์ด ESP32/Arduino และเซนเซอร์)
- **W11:** Lab 1 ชม. (การส่งข้อมูลผ่าน MQTT) + Project 1 ชม. (เขียนโค้ดรับส่งข้อมูลเซนเซอร์ขึ้น Dashboard)
- **W12:** Lab 1 ชม. (เทคนิคเข้ารหัสผ่าน/ความปลอดภัย) + Project 1 ชม. (ประยุกต์ใช้ความปลอดภัยในระบบ IoT + นำเสนอ)

### 🟪 Module 4: Computer Vision & System Integration (สัปดาห์ 13 - 17)
**Mini Project 4: "AI Object Detection System"** (ทักษะระบบวิทัศน์คอมพิวเตอร์และบูรณาการระบบ)
- **W13:** Lab 1 ชม. (อภิปราย Bias และจริยธรรม AI) + Project 1 ชม. (ดึงสตรีมภาพจากกล้องและทำ Object Detection เบื้องต้น)
- **W14:** Lab 1 ชม. (สร้าง CI/CD Pipeline ขั้นต้น) + Project 1 ชม. (เชื่อมระบบ CV เข้ากับ Web/IoT Dashboard เดิม)
- **W15:** Lab 1 ชม. (Virtual Tour/ดูงานศูนย์ข้อมูล) + Project 1 ชม. (เตรียมสไลด์รวมผลงาน 4 โมดูล)
- **W16:** นำเสนอโครงงานประยุกต์รวม (Final Capstone Presentation)
- **W17:** สอบปลายภาค (Final Examination)
