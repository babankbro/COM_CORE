# Edge Computing (การประมวลผลที่ขอบเครือข่าย)

## Definition
การประมวลผลข้อมูล **ใกล้แหล่งกำเนิดข้อมูล/ผู้ใช้** แทนที่จะส่งทุกอย่างขึ้นคลาวด์ ลดความหน่วง (latency) ประหยัดแบนด์วิดท์ และเพิ่มความเป็นส่วนตัว/ความพร้อมใช้งานแบบออฟไลน์

## Course Context
ตรงข้าม/เสริมกับ Cloud Computing ปรากฏในฮาร์ดแวร์-ซอฟต์แวร์ ([[Week 02 - Hardware & Software Ecosystems]]), เครือข่าย ([[Week 06 - Computer Networks & Internet]]) และเป็นรากของ [[TinyML และ Edge AI]] ในระบบฝังตัว ([[Week 11 - Embedded Systems & IoT]])
