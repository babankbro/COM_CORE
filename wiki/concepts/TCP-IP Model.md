# TCP/IP Model

## Definition
แบบจำลองการสื่อสารเครือข่าย **4 ชั้น** (Link, Internet, Transport, Application) ที่เป็นรากฐานของอินเทอร์เน็ต — IP จัดการที่อยู่/เส้นทาง, TCP รับประกันการส่งครบถ้วน, UDP ส่งเร็วแต่ไม่รับประกัน

## Course Context
แกนของหัวข้อเครือข่าย ([[Week 06 - Computer Networks & Internet]]) ใช้เทียบกับ OSI 7 ชั้น และอธิบายเหตุการณ์เมื่อพิมพ์ URL (DNS → TCP → HTTP)
