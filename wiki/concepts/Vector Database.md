# Vector Database (ฐานข้อมูลเวกเตอร์)

## Definition
ฐานข้อมูลที่ออกแบบมาเก็บและค้นหา **เวกเตอร์ฝังตัว (embeddings)** มิติสูง ด้วยการค้นความคล้าย (similarity search) รองรับงาน AI เช่น semantic search, ระบบแนะนำ และ [[RAG และ LLM|RAG]]

## Course Context
หมวด NoSQL ใหม่ที่สำคัญในหัวข้อฐานข้อมูล ([[Week 05 - Database & Data Management]]) และเชื่อมกับ AI ([[Week 10 - Generative AI & Modern Robotics]]); ปี 2025 ตลาดแตะ ~3.2 พันล้านดอลลาร์ โต ~24%/ปี และฐานข้อมูลหลัก (เช่น SQL Server 2025) เริ่มผนวกชนิด `VECTOR` เข้าไป
