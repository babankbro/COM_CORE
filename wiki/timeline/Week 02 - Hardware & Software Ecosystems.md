# สัปดาห์ที่ 2: ฮาร์ดแวร์ ซอฟต์แวร์ และระบบนิเวศสมัยใหม่

## 🎯 วัตถุประสงค์การสอน (Learning Objectives)
1. ผู้เรียนเข้าใจความสัมพันธ์และการทำงานร่วมกันระหว่างฮาร์ดแวร์และซอฟต์แวร์
2. ผู้เรียนรู้จักสถาปัตยกรรม Edge Computing และความสำคัญที่มีต่อระบบในปัจจุบัน
3. ผู้เรียนเข้าใจแนวคิด Green Computing และการประหยัดพลังงานในระบบคอมพิวเตอร์

## 📝 สรุปเนื้อหาหัวข้อ (Topics Covered)
- วิวัฒนาการของ Hardware และ Software Ecosystems
- สถาปัตยกรรม Edge Computing และความแตกต่างจาก Cloud Computing
- Green Computing: การออกแบบซอฟต์แวร์และฮาร์ดแวร์เพื่อความยั่งยืนและการประหยัดพลังงาน (Sustainability in Computing)

## 📚 อ้างอิง (References)
- Patterson, D. A., & Hennessy, J. L. (2020). *Computer Organization and Design RISC-V Edition: The Hardware Software Interface*. Morgan Kaufmann.
- IEEE Computer Society papers on Edge Computing and Green IT trends (2025-2026).
