# สัปดาห์ที่ 3: วงจรตรรกะและหน่วยประมวลผล

## 🎯 วัตถุประสงค์การสอน (Learning Objectives)
1. ผู้เรียนสามารถอธิบายหลักการทำงานของวงจรตรรกะ (Logic Circuits) พื้นฐานได้
2. ผู้เรียนเข้าใจสถาปัตยกรรมของไมโครโปรเซสเซอร์ โดยเฉพาะสถาปัตยกรรมแบบเปิดอย่าง RISC-V
3. ผู้เรียนสามารถเปรียบเทียบการทำงานและหน้าที่ของ CPU, GPU, NPU และ TPU ได้

## 📝 สรุปเนื้อหาหัวข้อ (Topics Covered)
- พีชคณิตบูลีนและวงจรตรรกะพื้นฐาน (Boolean Algebra & Logic Gates)
- โครงสร้างและสถาปัตยกรรมไมโครโปรเซสเซอร์ (Microprocessor Architecture)
- สถาปัตยกรรม RISC-V (Open Standard Instruction Set Architecture)
- หน่วยประมวลผลทางเลือกยุคใหม่: GPUs (Graphics Processing Units), NPUs (Neural Processing Units), TPUs (Tensor Processing Units) สำหรับ AI
