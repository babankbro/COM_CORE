# สัปดาห์ที่ 5: ฐานข้อมูลและการจัดการข้อมูลขนาดใหญ่

## 🎯 วัตถุประสงค์การสอน (Learning Objectives)
1. ผู้เรียนเข้าใจหลักการทำงานของระบบฐานข้อมูลแบบสัมพันธ์ (Relational) และแบบไม่สัมพันธ์ (NoSQL)
2. ผู้เรียนรู้จักแนวคิด Big Data และการจัดการข้อมูลขนาดใหญ่
3. ผู้เรียนเข้าใจความสำคัญและสถาปัตยกรรมของ Vector Databases ในยุคของปัญญาประดิษฐ์

## 📝 สรุปเนื้อหาหัวข้อ (Topics Covered)
- ระบบฐานข้อมูลพื้นฐาน (Relational Databases, SQL)
- ฐานข้อมูล NoSQL และการจัดการข้อมูลขนาดใหญ่ (Big Data Analytics)
- การทำงานของ Vector Databases (เช่น Pinecone, Milvus) เพื่อประยุกต์ใช้กับเทคโนโลยี Large Language Models (LLMs) และ RAG (Retrieval-Augmented Generation)

## 📚 อ้างอิง (References)

- ACM/IEEE-CS CC2020 - Information Management (IM).
- งานวิจัยและเอกสารเกี่ยวกับ Vector Databases และ RAG architecture (2024-2026).
