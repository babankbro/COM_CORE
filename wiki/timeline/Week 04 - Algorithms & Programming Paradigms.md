# สัปดาห์ที่ 4: อัลกอริทึมและการเขียนโปรแกรม

## 🎯 วัตถุประสงค์การสอน (Learning Objectives)
1. ผู้เรียนเข้าใจแนวคิดและสามารถออกแบบอัลกอริทึมพื้นฐานเพื่อแก้ปัญหาได้
2. ผู้เรียนรู้จักกระบวนทัศน์การเขียนโปรแกรม (Programming Paradigms) แบบต่างๆ
3. ผู้เรียนสามารถประยุกต์ใช้ AI Assistant ในกระบวนการเขียนโปรแกรมได้อย่างมีประสิทธิภาพ

## 📝 สรุปเนื้อหาหัวข้อ (Topics Covered)
- แนวคิดพื้นฐานด้านอัลกอริทึมและโครงสร้างข้อมูลเบื้องต้น
- กระบวนทัศน์การเขียนโปรแกรม (Procedural, Object-Oriented, Functional)
- การทำงานร่วมกับ AI ในการเขียนโค้ด (AI-assisted development, GitHub Copilot, Cursor)
- แนวคิดของ Agentic AI ในการจัดการและเขียนโปรแกรมอัตโนมัติ (AI as a Controller)

## 📚 อ้างอิง (References)

- ACM/IEEE-CS CC2020 - Software Development Fundamentals (SDF).
- บทความงานวิจัยล่าสุดเกี่ยวกับการเขียนโปรแกรมด้วยคู่หู AI (AI Pair Programming).
