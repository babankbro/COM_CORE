# สัปดาห์ที่ 9: ปัญญาประดิษฐ์และการเรียนรู้ของเครื่อง

## 🎯 วัตถุประสงค์การสอน (Learning Objectives)
1. ผู้เรียนสามารถอธิบายแนวคิดพื้นฐานของปัญญาประดิษฐ์ (AI) และการเรียนรู้ของเครื่อง (Machine Learning) ได้
2. ผู้เรียนรู้จักขั้นตอนในการสร้างและการฝึกสอนโมเดล (Model Training)
3. ผู้เรียนเข้าใจแนวคิด MLOps และความสำคัญในการนำโมเดลไปใช้งานจริง (Deployment)

## 📝 สรุปเนื้อหาหัวข้อ (Topics Covered)
- พื้นฐานของปัญญาประดิษฐ์และ Machine Learning (Supervised, Unsupervised, Reinforcement Learning)
- แนวคิดด้าน Deep Learning และโครงข่ายประสาทเทียม (Neural Networks) เบื้องต้น
- MLOps (Machine Learning Operations): กระบวนการพัฒนา, ทดสอบ, จัดเก็บ และนำโมเดลขึ้นระบบการผลิตจริง
