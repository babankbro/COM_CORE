# วิทยาการรหัสลับเบื้องต้น Cryptography

วิทยาการรหัสลับ (Cryptography) เป็นศาสตร์ที่ว่าด้วยการเข้ารหัส (Encryption) และถอดรหัส (Decryption) เพื่อปกป้องข้อมูลจากการถูกดักจับหรืออ่านโดยผู้ที่ไม่ได้รับอนุญาต เป็นรากฐานสำคัญที่ทำให้การสื่อสารบนโลกอินเทอร์เน็ตมีความปลอดภัย โดยสามารถแบ่งออกเป็น 3 ประเภทหลัก ได้แก่:

## 1. การเข้ารหัสแบบกุญแจสมมาตร (Symmetric-Key Cryptography)
ในระบบนี้ ทั้งผู้ส่งและผู้รับจะใช้ **"กุญแจเดียวกัน (Shared Key)"** ในการเข้ารหัสและถอดรหัสข้อมูล
- **ข้อดี:** ทำงานได้รวดเร็วมาก เหมาะสำหรับการเข้ารหัสข้อมูลขนาดใหญ่
- **ข้อเสีย:** ปัญหาในการแลกเปลี่ยนกุญแจ (Key Distribution) หากกุญแจถูกขโมยระหว่างทาง ข้อมูลทั้งหมดจะตกอยู่ในอันตราย
- **ตัวอย่างอัลกอริทึม:** AES (Advanced Encryption Standard), DES, 3DES

## 2. การเข้ารหัสแบบกุญแจอสมมาตร (Asymmetric-Key Cryptography)
ระบบนี้จะใช้กุญแจคู่ที่ทำงานร่วมกัน ได้แก่ **กุญแจสาธารณะ (Public Key)** สำหรับเข้ารหัส และ **กุญแจส่วนตัว (Private Key)** สำหรับถอดรหัส
- **กลไกการทำงาน:** หาก A ต้องการส่งข้อความลับให้ B, A จะนำ Public Key ของ B มาเข้ารหัสข้อความ เมื่อ B ได้รับข้อความ จะใช้ Private Key ของตนเอง (ที่ไม่มีใครรู้) ในการถอดรหัส
- **ข้อดี:** แก้ปัญหาการแลกเปลี่ยนกุญแจได้อย่างสมบูรณ์แบบ
- **ข้อเสีย:** การคำนวณทางคณิตศาสตร์ซับซ้อน ทำให้ทำงานช้ากว่าแบบสมมาตร
- **ตัวอย่างอัลกอริทึม:** RSA, ECC (Elliptic Curve Cryptography)

## 3. ฟังก์ชันแฮช (Hash Functions)
ฟังก์ชันแฮชไม่ใช่การเข้ารหัสเพื่อถอดกลับ แต่เป็นการนำข้อมูล (Plaintext) ขนาดใดก็ได้มาผ่านสมการคณิตศาสตร์ เพื่อสร้าง "ค่าแฮช (Hash Value/Digest)" ที่มีขนาดคงที่
- **คุณสมบัติ:** เป็นฟังก์ชันทางเดียว (One-way) ไม่สามารถแปลงค่าแฮชกลับเป็นข้อมูลเดิมได้ และหากข้อมูลเปลี่ยนไปแม้แต่บิตเดียว ค่าแฮชจะเปลี่ยนไปโดยสิ้นเชิง (Avalanche Effect)
- **การนำไปใช้:** ใช้ตรวจสอบความถูกต้องของข้อมูล (Data Integrity), การเก็บรหัสผ่าน (Password Hashing)
- **ตัวอย่างอัลกอริทึม:** SHA-256, SHA-3, MD5 (ปัจจุบันไม่แนะนำให้ใช้)

## การประยุกต์ใช้งานจริง
ในทางปฏิบัติ มักจะมีการใช้งานทั้งสามแบบร่วมกัน (Hybrid Cryptography) เช่น โปรโตคอล **TLS/SSL (HTTPS)** ที่ใช้ Asymmetric Key ในการแลกเปลี่ยนกุญแจอย่างปลอดภัยในตอนเริ่มต้น จากนั้นใช้ Symmetric Key เพื่อเข้ารหัสการส่งข้อมูลจริงเนื่องจากทำได้รวดเร็วกว่า
