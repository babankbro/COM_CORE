# Heterogeneous Computing (CPU + GPU + NPU)

> **หมวดหมู่:** เนื้อหาเชิงลึกประกอบการเรียนรู้ (Deep Dive Learning Content)

## 📖 เนื้อหาและคำอธิบาย
ในอดีต การเพิ่มความเร็วของคอมพิวเตอร์ทำได้โดยการเพิ่มสัญญาณนาฬิกา (Clock Speed) และเพิ่มจำนวน Core ของ CPU แบบดั้งเดิม (Homogeneous Multi-core) แต่เมื่อถึงขีดจำกัดของความร้อนและกฏของมัวร์ (Moore's Law) เริ่มชะลอตัว แนวทางการออกแบบจึงมุ่งสู่ **Heterogeneous Computing** สถาปัตยกรรมที่รวมชิปหรือหน่วยประมวลผลหลากหลายประเภทไว้ด้วยกันเพื่อทำงานเฉพาะกิจ

### 1. ทำไมต้องใช้หน่วยประมวลผลหลายแบบ?
หลักการสำคัญคือ "ใช้เครื่องมือให้เหมาะสมกับงาน"
- **CPU (Central Processing Unit):** เหมาะสำหรับงานประมวลผลทั่วไปแบบอนุกรม (Sequential), โค้ดที่มีเงื่อนไข If-Else ซับซ้อน และการจัดการระบบปฏิบัติการ (OS) 
- **GPU (Graphics Processing Unit):** มีคอร์ขนาดเล็กนับพันตัว เหมาะสำหรับงานประมวลผลแบบขนาน (Parallel Processing) จำนวนมหาศาล เช่น การเรนเดอร์กราฟิก และการคำนวณเมทริกซ์ 
- **NPU (Neural Processing Unit) หรือ AI Accelerator:** ออกแบบวงจรมาเป็นพิเศษสำหรับทำ Tensor Math Operations ใน Machine Learning (เช่น การคูณและบวกแบบรวดเร็ว) ช่วยลดการใช้พลังงานได้มหาศาลเมื่อเทียบกับการรัน AI บน CPU 

### 2. System on a Chip (SoC)
ในสมาร์ทโฟนและคอมพิวเตอร์ยุคใหม่ (เช่น ชิป Apple Silicon M-Series หรือ Qualcomm Snapdragon) การออกแบบก้าวไปสู่ระดับ **SoC** คือการแพ็กทุกอย่าง (CPU, GPU, NPU, Memory, ISP สำหรับประมวลผลภาพ และ Secure Enclave) รวมไว้ใน Die ชิปซิลิคอนแผ่นเดียวกัน 

สถาปัตยกรรมแบบนี้มีข้อได้เปรียบสูงมากในเรื่องของ **Unified Memory** หรือการใช้พื้นที่หน่วยความจำร่วมกัน ทำให้ไม่ต้องเสียเวลาและพลังงานไปกับการคัดลอกข้อมูลไปมาระหว่าง System RAM และ VRAM บนการ์ดจอแยก ซึ่งช่วยลดคอขวด (Bottleneck) และประหยัดพลังงานได้ล้นหลาม

### 3. ความท้าทายฝั่งนักพัฒนา (Software Challenge)
แม้ฮาร์ดแวร์จะก้าวหน้าไปมาก แต่การเขียนโปรแกรม (Programming Model) กลับมีความท้าทายมากขึ้น นักพัฒนาต้องใช้ API หรือเฟรมเวิร์กเฉพาะทาง เช่น CUDA, OpenCL, Metal หรือ SYCL เพื่อกำหนดและกระจายงาน (Workload) ไปยังโปรเซสเซอร์ตัวที่เหมาะสม จึงเป็นหน้าที่ของวิศวกรและสถาปนิกซอฟต์แวร์ที่ต้องออกแบบระบบให้ใช้ประโยชน์จากฮาร์ดแวร์ที่ซับซ้อนนี้ได้เต็มศักยภาพที่สุด
