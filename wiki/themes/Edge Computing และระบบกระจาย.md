# 🌐 ธีม: Edge Computing และระบบกระจาย

> แนวโน้มการย้ายการประมวลผลจาก "ศูนย์กลาง (cloud)" ไปสู่ "ขอบเครือข่าย (edge)" ที่ใกล้ผู้ใช้/ข้อมูล

## เส้นเรื่อง
[[Edge Computing]] ลดความหน่วง ประหยัดแบนด์วิดท์ และเพิ่มความเป็นส่วนตัว ปรากฏซ้ำหลายหัวข้อ:
- ระดับฮาร์ดแวร์/ซอฟต์แวร์ → [[Week 02 - Hardware & Software Ecosystems]]
- ระดับเครือข่าย (Edge networks, 5G/6G) → [[Week 06 - Computer Networks & Internet]]
- ระดับอุปกรณ์ ([[TinyML และ Edge AI]] บนไมโครคอนโทรลเลอร์) → [[Week 11 - Embedded Systems & IoT]]

## บทเรียนสำคัญ
สถาปัตยกรรมสมัยใหม่เป็น "สเปกตรัม" ระหว่าง cloud ↔ edge ไม่ใช่ทางเลือกขั้วเดียว — การออกแบบต้องสมดุลระหว่างพลังประมวลผล พลังงาน ความหน่วง และความเป็นส่วนตัว
