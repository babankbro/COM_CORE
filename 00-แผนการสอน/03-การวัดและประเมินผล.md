# 📊 การวัดและประเมินผล (Assessment & Evaluation)

ออกแบบให้สอดคล้องกับ [[01-ผลลัพธ์การเรียนรู้-CLO]] โดยเน้นการประเมินตามสภาพจริง (authentic assessment) มากกว่าการท่องจำ

## 💯 สัดส่วนคะแนน

| องค์ประกอบ | สัดส่วน | CLO ที่ประเมิน | รูปแบบ |
|---|:---:|:---:|---|
| สอบกลางภาค | 20% | CLO1–3 | ปรนัย + อัตนัยประยุกต์ |
| สอบปลายภาค | 25% | CLO4–5 | ปรนัย + กรณีศึกษา |
| ปฏิบัติการรายสัปดาห์ (9 ใบงาน) | 20% | CLO2–5 | ใบงานแล็บ + ส่งผลงาน |
| โครงงานกลุ่ม + การนำเสนอ | 15% | CLO3, CLO6 | ผลงาน + presentation (rubric) |
| รายงานการดูงานอุตสาหกรรม | 10% | CLO6 | รายงานรายบุคคล/กลุ่ม |
| การมีส่วนร่วม/จิตพิสัย/อภิปรายจริยธรรม | 10% | CLO5–6 | สังเกต + rubric |
| **รวม** | **100%** | | |

## 🎓 เกณฑ์การตัดเกรด (อิงเกณฑ์ — ปรับตามระเบียบสถาบันได้)

| เกรด | ช่วงคะแนน | เกรด | ช่วงคะแนน |
|:---:|:---:|:---:|:---:|
| A | 80–100 | C+ | 60–64 |
| B+ | 75–79 | C | 55–59 |
| B | 70–74 | D+ | 50–54 |
| C+ | 65–69 | D | 45–49 |
| | | F | < 45 |

## 📏 Rubric: การนำเสนอโครงงาน (15 คะแนน)

| เกณฑ์ | ดีมาก (3) | ดี (2) | พอใช้ (1) |
|---|---|---|---|
| **ความถูกต้องเชิงเทคนิค** | อธิบายหลักการถูกต้อง เชื่อมโยงเนื้อหาในวิชา | ถูกต้องเป็นส่วนใหญ่ | มีข้อผิดพลาดสำคัญ |
| **การประยุกต์/ความคิดสร้างสรรค์** | แก้ปัญหาจริง มีมุมใหม่ | ประยุกต์ได้พอควร | ลอกแบบตรง ๆ |
| **การนำเสนอ/สื่อสาร** | ชัดเจน ตรงเวลา สื่อช่วยดี | สื่อสารเข้าใจได้ | ติดขัด/ไม่ตรงเวลา |
| **การทำงานเป็นทีม** | แบ่งงานชัด ทุกคนมีส่วนร่วม | มีส่วนร่วมส่วนใหญ่ | พึ่งบางคน |
| **การตอบคำถาม** | ตอบลึก เข้าใจจริง | ตอบได้พื้นฐาน | ตอบไม่ได้ |

## 📏 Rubric: อภิปรายจริยธรรม/IP (สัปดาห์ 14)
ประเมิน: (1) ระบุประเด็นเชิงจริยธรรม/กฎหมายได้ชัด (2) อ้างหลักการ เช่น [[11-จริยธรรมทางคอมพิวเตอร์|จรรยาบรรณ ACM / หลัก UNESCO]] (3) รับฟังและโต้แย้งอย่างมีเหตุผล (4) เสนอแนวปฏิบัติที่รับผิดชอบ

## ✅ แนวปฏิบัติเรื่องความซื่อสัตย์ทางวิชาการ
- การใช้ AI ช่วยงาน (เช่น ผู้ช่วยเขียนโค้ด) **อนุญาตแบบมีเงื่อนไข**: ต้องอ้างอิงการใช้งานและอธิบายผลงานของตนเองได้ — สอดคล้องกับประเด็นใน [[12-ทรัพย์สินทางปัญญา]] และ [[11-จริยธรรมทางคอมพิวเตอร์]]
- ลอกผลงาน/ละเมิดลิขสิทธิ์ → ตามระเบียบสถาบัน
