# 2 · ฮาร์ดแวร์และซอฟต์แวร์ (Hardware & Software)

> [!abstract] สาระสำคัญ
> คอมพิวเตอร์ทำงานเป็น **ชั้น (layers)**: ฮาร์ดแวร์ (สิ่งที่จับต้องได้) ↔ เฟิร์มแวร์/ระบบปฏิบัติการ ↔ ซอฟต์แวร์ประยุกต์ ผู้เรียนต้องแยกแยะองค์ประกอบและเข้าใจว่าซอฟต์แวร์สั่งงานฮาร์ดแวร์ผ่าน OS ได้อย่างไร

## 🧩 แนวคิดหลัก
- **องค์ประกอบฮาร์ดแวร์:** หน่วยประมวลผล (CPU/GPU/NPU — ดู [[03-วงจรตรรกและหน่วยประมวลผล]]), หน่วยความจำ (RAM/ROM), หน่วยเก็บข้อมูล (SSD/HDD), อุปกรณ์ I/O, เมนบอร์ด/บัส
- **ลำดับชั้นหน่วยความจำ (memory hierarchy):** register → cache → RAM → storage (เร็ว–แพง–เล็ก ลงไป ช้า–ถูก–ใหญ่)
- **ประเภทซอฟต์แวร์:** ระบบ (system software — OS, drivers, utilities) vs ประยุกต์ (application software)
- **ระบบปฏิบัติการ (OS):** จัดการกระบวนการ หน่วยความจำ ไฟล์ และอุปกรณ์ เป็นตัวกลางระหว่างโปรแกรมกับฮาร์ดแวร์ (Windows, Linux, macOS, Android)
- **โอเพนซอร์สvs proprietary:** โมเดลลิขสิทธิ์และการใช้งาน เชื่อมกับ [[12-ทรัพย์สินทางปัญญา]]

## 📈 แนวโน้มปัจจุบัน (2025–2026)
- **การประมวลผลแบบเฉพาะทาง (heterogeneous computing):** ชิปสมัยใหม่รวม CPU + GPU + NPU บนแพ็กเกจเดียว เพื่อรองรับ AI บนเครื่อง (on-device AI)
- **On-device / Edge AI:** โมเดลทำงานบนอุปกรณ์โดยไม่พึ่งคลาวด์ตลอดเวลา — กระทบการออกแบบทั้งฮาร์ดแวร์และซอฟต์แวร์ (เชื่อม [[08-ระบบฝังตัว]])
- **คอนเทนเนอร์/เวอร์ชวลไลเซชัน:** ซอฟต์แวร์สมัยใหม่ deploy ผ่าน container (Docker) และคลาวด์ ทำให้เส้นแบ่งฮาร์ดแวร์จริง/เสมือนเบลอ (เชื่อม [[09-ศูนย์ข้อมูล]])

## 🔗 ทำไมสำคัญต่อวิชานี้
เป็นฐานเชื่อมระหว่างฮาร์ดแวร์ระดับวงจร ([[03-วงจรตรรกและหน่วยประมวลผล]]) กับซอฟต์แวร์ระดับสูง ([[04-อัลกอริทึมและโปรแกรม]])
